Architecture

What runs thetrail

thetrail teaches a language along a real long-distance trail. A learner moves stage by stage and learns the vocabulary of hospitality from the people on the road.

One Worker serves each site.

Each site has a database and a bucket of its own. The walk is a React app, and every other page is plain HTML from the same Vite build. Recording and checking run offline, and no learner's request ever starts them.

  • Both sites run on the Cloudflare Workers Free plan. A request past a limit fails and costs nothing, so each design works inside the limits.
  • The Worker runs TypeScript with no framework. Its only outside code is a vendored AWS request signer.
  • The client runs React 19 with no router library. The app shows the pages a trail's data declares, and Tailwind CSS gives the whole domain one stylesheet.
  • Python tools do the offline work. They record the clips and deploy each site.

Three rules govern the design.

  • Every route declares who may reach it, and a test holds the public list closed.
  • A trail is a pack of data, and a blind translation checks every Spanish line.
  • Each release cycle leaves a measured record.
